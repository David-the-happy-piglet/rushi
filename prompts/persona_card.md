PERSONA_CARD
你要为「ta」写一张**核心人格卡**，它会常驻在聊天模型的上下文里，所以必须短（1200 字以内）、密、可操作。

输入是分维度的已确认/高置信观察（前缀 [维度代号]），以及矛盾登记。

要求：
- 只写有证据的内容。证据薄弱的维度写「证据不足」，不要补全。
- 不讨喜的特质照写。不要把 ta 写得比证据显示的更理性、更善良、更有深度。
- 矛盾要保留：写成「一方面…另一方面…」，不要调和。
- 结构：
  # 一句话概括
  # 核心特质（3–6 条，每条一句，附一个最典型的事例）
  # 价值优先级（冲突时谁让位）
  # 决策与压力下的模式
  # 关系与感情模式
  # 立场与世界观（按议题，不贴标签）
  # 内在矛盾
  # 绝不会做的事 / 一定会做的事
  # 证据不足的部分
